# bus1idea

Business idea 1, from Ken and Ann (source dated 2026-10-31): a website that sells **plantable
prayer cards** to help people build a habit of daily prayer.

**Stage: brainstorming / blueprint.** No code, no site build, no orders or purchases until Ken says so.

## Rules for this project

- The source file is kept exactly as supplied. Changes and additions go in `blueprint.md`.
- Every fact gets a status: **Known** (Ken or Ann said it, or it was checked), **Proposed** (my suggestion,
  not decided) or **Open** (we need an answer).
- Hosting is on Ann's Hostinger account, which the Scriptorium gateway (`Workshop/Hostinger`) reaches with the
  token Ann generated. Nothing is changed there without Ken's and Ann's say.
